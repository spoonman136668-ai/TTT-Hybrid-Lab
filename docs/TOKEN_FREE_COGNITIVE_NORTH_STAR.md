# TTT-Hybrid-Lab — strictly token-free cognitive North Star

**Status: prospective target architecture / no scientific promotion.**
This constraint applies to the *native Hybrid intelligence architecture* equally with Wingless and Yggdrasil. The projects retain independent implementations, research owners, source custody and budgets.

## Destination and strict exclusion

Build a standalone, persistent, continually learning, causally reasoning cognitive system with eventually LLM-class capability or better at reduced compute/memory where achievable, **without tokens in its learned cognitive pipeline**. In particular:

- No language token IDs/vocabularies, tokenizer/BPE/subword segmentation, or token-conditioned model input states.
- No autoregressive next-token objective, token-sequence world modeling, token-keyed episodic memory, token-level planning, or token-generating decoder.
- No rebranding of token embeddings as 'continuous latent states' or hiding an external tokenizer/LLM behind a wrapper. Capability must come from Hybrid's own learned state.
- Modal input/output may involve natural language, sound, images and other signals; external serialization for software is not a licensed token-based cognitive boundary. The native learned perceptual/decision/generation path must remain independent of text tokenization.
- Strong conventional token-based models may be separately trained **external controls only**, not part of the target or an acceptable shortcut to its cognitive capabilities.

## Hybrid's distinct mechanism family

Preserve a genuinely hybrid scientific strategy, with selective state-space recurrence (Mamba/SSM), causal attention, test-time adaptation, conditional computation, and potentially JEPA-like multi-view prediction *over non-tokenized learned causal/world state*. Attention weights over continuous dynamical state are not, by themselves, a language-token architecture; the task is to prove they can learn meaningful native cognition and causal transfer without tokenization.

Required native work: construct a non-tokenized observation/latent/event-state interface (avoid fixed lexical units), train a state/dynamics learning objective, learn interventions/action consequences, preserve state across cold sessions, resist catastrophic interference, reason compositionally, and produce useful language/action behavior through native representations.

## Scientific falsification

Before the *first* token-free candidate's science run, preregister task families, unseen transfer splits, strong fully-trained controls (including conventional TTT and token-based LMs **only as external baselines**), resource-matched arms, negative/scramble ablations, fidelity of action interventions, cold retention tests, incremental learning, reasoning/communication competence, memory bytes, GPU compute/latency, whole-process cost and stop/accept thresholds. A scientific success requires measured superiority to the strongest matched control on predeclared endpoints, not just a functioning interface.

## Current gap — do not overclaim

Current root `model.py` and `README.md` document **token-conditioned diagonal SSM** and **tokenwise router**. These are **not compliant with the strict token-free North Star**. Pinning authentic Mamba2 and TTT kernels, Windows CPU regression, S24 good views, S25 contradiction gating or S26 budget-reserve diagnostics does **not** by itself eliminate tokens or establish native learning, reasoning, transfer, retention, efficiency or RSI.

Keep every existing frozen protocol, reference/source pin, original seed/heldout custody, development result and negative outcome. This is **not** authorization to convert old token-based experiments retroactively or start GPU training. A separate architecture candidate and owner-scoped first-use authorization are required. Neither FORGE's advisory proposal nor Wingless/Yggdrasil research acquires cross-project execution authority.
