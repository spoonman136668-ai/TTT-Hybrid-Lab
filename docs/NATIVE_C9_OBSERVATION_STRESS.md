# C9 — Action imbalance and missing factual-feedback robustness of *trained* native-memory routing

## Why C9 is a distinct substantive gate

[C8 PR #77](https://github.com/spoonman136668-ai/TTT-Hybrid-Lab/pull/77) successfully integrated actual P7 gradient-trained factual-history routing and a separately trained conventional MLP with source-verified P3 native-memory snapshots, but **did not beat the conventional MLP in any of six fixed-schedule comparisons**. Original P7 also lost to the MLP in validation for all three train seeds. The simple P6 hand-coded sign rule performed *better* than both learned selectors in that special clean, regularly alternating intervention schedule. C9 attempts to falsify robustness before further integration by independently varying the **intervention distribution** and the **rate at which realized factual feedback is revealed**, while keeping all seven previously tested core source components unchanged.

C9 is not a new router, alternative scheduler, or controller. It uses the exact source of P7 PR #62 copied in C8, the existing C8 actual-training helper, C7 saved native-memory prediction API and P6 factual detector. Original independent P7/P8/P9/P10/P11/P12 research is untouched.

## Frozen before first C9 evaluation

`experiments/native_c9_observation_stress_dev_frozen.json` fixes model initialization seeds, original P7 training and held-out **development** RNG source, the **three** evaluation stress conditions, dedicated synthetic DEV stream seeds and hypotheses. Its declared artifact/source parents include exact C8 SHA `dc9288552d91c1f56051b0d348ca8ca8e98e2bb4` and P7 original Git blob `7db1fe42695f16bf2afe730f4348210156ac3c24`.

**Training:** unchanged P7 public factual source and original P3 native model. Three pairs of P7/MLP model fits (`303,307,311`) with the same original 6,000 examples, distinct-RNG 1,920 DEV validation examples, exactly **600 factual AdamW updates × 256** and identical seed+9999 sampled minibatch ordering (P7: 828 params; conventional: 849). Each trained pair uses the original P7 fitted weights without posthoc selection. Three original P3 continuous native learner model seeds (`46111,46117,46129`) run exactly 40 old + 40 reversed signed-action factual updates, save immutable root→40→80 C2-validated cold restores. Both actual saved fast memories and step80 model/optimizer are **immutable throughout C9 evaluation**.

**Development stream generator:** 96 events per test, Bernoulli 6% hidden-sign regime flips, randomized initial sign, familiar P3 analytic gain `±0.45` and intercept `0.04`, added Gaussian 0.025 outcome noise and intervention actions `±1`. Two fixed DEV stream seeds per native/P7 pair; random streams are different from P7 training and validation RNG sources, but **still share the same public known synthetic causal family**, and are not independent scientific unfamiliar worlds. All arms see the **same** realized sequence (three seeds × three conditions × two streams = **18 full traces**).

Three predeclared conditions: **balanced** (50/50 actions, 100% realized feedback released), **action-imbalanced** (90% positive actions, 100% feedback), and **sparse feedback** (50/50 actions, only 45% Bernoulli selected realized outcomes revealed to every nonoracle selector). Unrevealed outcomes are still used for evaluation **but never added to the observed factual history**. The common causal mask is sampled independently of selector actions; outcomes are produced **after** all predictions. Each learned selector sees the same last 8 genuinely *revealed* completed factual pairs, and performs the same two hypothetical-action **predictions** with no hypothetical *outcome*. It has no current hidden label, switch age, schedule, event index or future consequence. The P6 fixed sign estimator also sees only those revealed completed pairs.

Six frozen arms: genuinely gradient-trained P7, genuinely trained conventional MLP, P6 source fixed factual-effect rule, always choose recent memory, evaluator-only oracle true context upper bound, and trained P7 fed all-zero history. Each model uses precisely the same current step80 native weights and selects either the source-restored step40 old fast memory grafted into cloned current recurrent/history, or the original step80 native memory, with no new memory writes or optimizer updates.

**Measurements:** full-event error, mature post-switch prediction MSE and correct-context route accuracy (events ≥8 after the evaluator's most recent hidden change), immediate post-switch error, revealed factual feedback fraction, context-switch count, source/checkpoint weights and ancestry SHA-256s, exact raw per-event causal ledger and digests, mean conditioned comparison, and wall-clock/inference time. Every trace and negative result remains in the artifact; no seeds are discarded even when the generated context switches are inconvenient.

### Fixed DEV hypotheses — explicitly not acceptance criteria

Across each six-record condition, report the count supporting: P7 mature accuracy ≥75%; P7 mature MSE better than always-new memory by ≥0.05; P7 mature MSE better than the **separately trained MLP** by ≥0.01; P7 better than original fixed P6 by ≥0.02; and P7 better than its all-zero history ablation by ≥0.05. A **FAIL** across all configurations is a useful falsification and **must not be retuned into a pass**. This is not a preregistered independent *scientific* threshold.

## Fairness and authority

Both trained models get identical historical factual information, the same original training sample indices/updates and two routing prediction calls. Their parameter counts are near equal, but **original P7 and MLP architecture compute/FLOPs and whole-process cost are not independently matched**, so the comparison is not a scientific compute-controlled winner determination. The P6 hand-coded heuristic is not a trained, compute-matched conventional model. Oracle has privileged context known to the evaluator alone and must never be used as an informed control. Changes in observation availability affect all nonoracle selectors, and the experiment measures accuracy rather than assuming missing feedback can be magically reconstructed.

The generator is a familiar algebraic development source. No official S26/S27 first-use, sealed independently born worlds, stable lifelong memory, unfamiliar causal transfer, fully converged controls, live FORGE integration, new controller or runner, encrypted off-host archive or automatic acceptance/promotion is authorized. Existing project P12, P11 and P9 GPU studies continue in their own independent branches. P7/P8 original experiments remain intact.
