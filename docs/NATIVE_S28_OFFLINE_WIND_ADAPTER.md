## What has been built

`scripts/native_s28_causal_wind_offline.py` contains two separately safe seams:

- **Exact third-party source audit, without importing or executing the source.** Given an *already checked out* Git repository, the auditor demands the precise [CausalAILab/Causal-Gymnasium](https://github.com/CausalAILab/Causal-Gymnasium) upstream commit `c94e9a4cd3641588b6b8507e71ccee5c27032bdf`, an unchanged detached/clean working tree, and eleven explicitly frozen Git blob hashes (wind SCM and PCH module, core API, its package initializer, setup, and LICENSE). It parses the wind module as Python AST to verify the public SCM `reset/step/sample_u` and PCH `see/do/ctf_do` methods and mandatory NumPy/Gymnasium imports. It does not instantiate a world. Repeated source paths with symlinks, dirty commit, wrong blob or altered API fail closed.
- **Dependency-free pure factual observation adapter.** It accepts one already completed external step tuple `(observed_next_state, factual_reward, terminated, truncated, info)` and the *actually executed* action 0 or 1. It emits only the previously observed public four-vector, executed action, subsequent four-vector, reward and termination flags. The untrusted `info` map is never passed to a learner or retained. Keys naming hidden wind, latent context, oracle, counterfactual or causal graph are rejected. It cannot call `reset/step/ctf_do`, read private `_env`, invoke an optimizer, choose actions, or import upstream packages. The tests feed completed transitions from a small local synthetic fixture, **never the real external world**.

A source-audit workflow may use `actions/checkout` to obtain the **public upstream repository at its exact 40-byte commit ID**, read-only, inside the isolated GitHub project-owned runner checkout. This is not a `pip install`, build, simulator import, world reset, science first-use, or download from an unauthenticated website. The upstream source files themselves are **not copied into the Hybrid repository or uploaded to artifacts**. The auditable receipt contains only hashes and status.

The upstream `setup.py` declares broad dependencies including `gymnasium[all]`, `pygame`, `box2d-py`, `highway-env`, `networkx`, `pydash`, `toposort`, `numpy<=1.26.4`; the package's `causal_gym/envs/__init__.py` eagerly imports many non-CartPole environments.
