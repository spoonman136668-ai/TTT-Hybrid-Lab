## Why this experiment

The authentic P32 owner #42548762315 confirmed actor-head-only PPO reached
200/200 source return under three previously observed model seeds, with full
recurrent PPO around 99–124 and a two-frame conventional rule at 200.
The frozen P32 all-seed general-acquisition gate was **FAIL** due to recurrent
only failure; source 4507 was previously selected, not independent. A fresh
actor-only result needs disjoint model/train/evaluation worlds and the strongest
conventional source control reported without a false architecture claim.

P33 reuses original P32 PPO implementation *without modifying its source*:
full recurrent PPO, actor-head-only PPO with recurrent weights bitwise frozen,
and critic-only no-actor-update negative. New prospective model seeds, train
resets and physics evaluations are specified in the immutable protocol.
It records 442,368 real action/reward training steps and 5,184 optimizer
minibatches **if the authorized owner executes it**. The runner must witness
unconsumed seed reservations before first use. Merely committing this script
does not consume original worlds or satisfy those reservations.

## Model custody

Each actor-head candidate is written by exclusive-create to a **new scratch
directory outside the source checkout**, with SHA-256 weight bytes, exact
P32-compatible cold loading, matching logits, trace identifiers, seed and
heldout metrics. An interrupted or partially written candidate must not be
replayed in-place. No accepted/latest model pointer, training owner checkpoint,
optimizer state, AdamW continuity, cross-host replica, or offsite backup is
created. This is **model-weight cold retention**, not a completed continuous
training/release/backup subsystem.

No arbitrary file downloads, API calls, timers, background schedulers,
cross-project credentials or other research lanes.
